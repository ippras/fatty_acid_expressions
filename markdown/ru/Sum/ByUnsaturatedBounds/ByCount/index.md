# Сумма по количеству ненасыщенных связей
 
 - Насыщенные жирные кислоты
   
   - НЖК
   - ровно 0 неасыщенных связей
 - Мононеасыщенные жирные кислоты
   
   - МНЖК
   - ровно 1 неасыщенная связь
 - N неасыщенные жирные кислоты
   
   - NUFA
   - ровно N неасыщенных связей
 - Жирные кислоты
   
   - ЖК
   - 0 или более неасыщенных связей
 - Неасыщенные жирные кислоты
   
   - ННЖК
   - 1 или более неасыщенных связей
 - Полинеасыщенные жирные кислоты
   
   - ПНЖК
   - 2 или более неасыщенных связей
