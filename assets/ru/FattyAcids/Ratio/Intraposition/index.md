# Fatty acids intraposition ratio
 
 The ratio between fatty acids in the same stereospecific position.
 
 - Fish lipid quality
   - FLQ
 - Health-promoting index
   - HPI
 - Снижающие уровень холестерина жирные кислоты к повышающим уровень холестерина жирным кислотам
   - H/H
 - Индекс атерогенности
   - IA
 - Индекс тромбогенности
   - IT
 - Линолевая жирная кислота к α-линоленовой жирной кислоте
   - LA/ALA
 - Полинеасыщенные омега -6 жирные кислоты к полинеасыщенные омега -3 жирным кислотам
   - $PUFA\[\\omega-6\]/PUFA\[\\omega-3\]$
 - Полинеасыщенные жирные кислоты к насыщенным жирным кислотам
   - ПНЖК/НЖК
