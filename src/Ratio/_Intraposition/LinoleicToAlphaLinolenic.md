# Linoleic fatty acid to α-Linolenic fatty acid

$$\frac{C18:2[\omega-6]}{C18:3[\omega-3]}$$

## Abbreviations

- LA/ALA

## Description

Used for guiding infant formula development.

**Interpretation**:

- from 5:1 to 15:1 ([Einerhand (2023)])
- below 4:1 is not recommended ([Clark (1992)])
